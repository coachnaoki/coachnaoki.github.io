02リポジトリ取得

準備を始めましょう。

① まず、 naoki-blueprint を置く専用フォルダを作成

Finder (Mac) / エクスプローラ (Win) で、 動画制作用の空フォルダを好きな場所に作ります (例: フォルダ名「video」 / 場所はデスクトップでも書類でも OK)。

② そのフォルダのパスをコピー

  • Mac: Finder でフォルダを右クリック → 「option」 キーを押すとメニューが切り替わる → 「"video" のパス名をコピー」
  • Windows: エクスプローラで作成したフォルダを開く → 上部のアドレスバーをクリックするとパス (例: C:\Users\…\video) が表示される → 選択してコピー

③ ターミナル (Cursor 下部) で cd の後ろにコピーしたパスを貼り付け

⚠ 下の例はそのままコピペしない。 cd (cd の後ろに半角スペース) を打ってから、 ②でコピーしたパスを貼り付けて Enter。

例 (Mac でデスクトップに video を作った人の場合):

cd /Users/<ユーザー名>/Desktop/video

④ リポジトリをダウンロード（Mac / Windows 共通・このコマンドはそのままコピペでOK）:

git clone https://github.com/coach-naoki/naoki-blueprint.git

03Claude Code を起動して動画作成開始

① ダウンロードしたフォルダに入る（このコマンドもそのままコピペでOK）:

cd naoki-blueprint

② Claude Code を起動（Mac / Windows 共通）:

claude --dangerously-skip-permissions

③ Claude Code 内で /new-video を実行:

/new-video

📌 初回のみ: /new-video を実行するとライセンスコード (例: NK-XXXX-XXXX-XXXX) の入力を求められます。 このページの下部に表示されているライセンスIDをコピーして貼り付けてください。

起動すると、以下を順に聞かれます:

  1. 動画タイプ (横動画 / ショート動画)
  2. プロジェクト名（日付でOK。例: 2026-04-19）
    📂 ここでプロジェクトが作成され、public/videos/main/ フォルダが自動で開きます
    下の 「04 素材を配置」 のフォルダ構成を参考に、本編動画など必要な素材をドラッグ＆ドロップしてください。
    ※ 残りの質問 (③〜⑤) はそのまま続けて答えてOK。 step01 が始まるまでに素材を入れ終えれば大丈夫です。
  3. プロファイル (動画のトンマナ・テロップデザイン・アニメ・特殊コンポ・動画エフェクト・OP/ハイライト構成・BGM/SE 音量・オートモード設定など、 過去動画で蓄積したカスタマイズを引き継ぐ場合に選択。 初回は 「プロファイルなし」 でOK)
  4. オートモード (途中の確認をスキップして一気に進めるか)
  5. 対談動画かどうか (インタビュー / 対談ならインタビュアーとインタビュイーで字幕色を分けます)

04素材を配置 → 作業開始

フォルダ構成 (projects/<プロジェクト名>/public/):

🎬ワークフローの全体像

動画づくりは 4つのフェーズ で進みます。 最初に /new-video と打つだけで、 あとは AI が「次はこれをやります」 と1つずつ案内してくれます。 基本は順番通りに Enter を押していくだけ で1本の動画が完成します。

PHASE 1 素材準備

撮影した動画を AI に渡すと、 話している内容を 自動で文字に書き起こし 。 「えーと」「あのー」 「言い直し」 「長い無音」 を AI が一括カット してくれます。 ここまでで、 撮りっぱなしの動画が「編集前」 の状態に整います。

PHASE 2 動画の土台づくり

テロップのデザインを ブラウザでクリックして選ぶだけ。 AI が話の内容に合わせてテロップを自動配置（重要な部分は強調スタイル、 否定は赤、 など8種類から自動判定）。 効果音もつけて、 動画の骨格が完成します。

PHASE 3 演出を足す （必要なものだけ）

使いたい演出だけ追加できます: グリーンバック背景置換 ・ デモ動画やスクショの差し込み ・ スライド挿入 ・ ワイプ（顔出し小窓） ・ 画像挿入（AI生成も可）。 いらないものは飛ばしてOK 。 シンプルに行きたい人は丸ごとスキップもできます。

PHASE 4 BGMを入れて書き出し

BGM を入れて（動画の長さに自動で合わせて、 フェードイン/アウトも自動）、 最後に MP4 として書き出し → 完成 🎉。 横動画は「本編から ハイライト動画を自動でつくる」 おまけ機能つき。

📐 横動画 と ショート動画 の両方つくれます
/new-video を打つと「横とショートどっち？」 と聞かれるので選ぶだけ。 ショート動画はスライド・ワイプ・OP/ED など一部演出を省略した シンプル構成 です。
💡 途中で休憩したくなったら: /catchup と打つと、 AI が「いまどこまで進んだか」 「次は何をすればいいか」 を教えてくれます。 気軽に休憩OK。
▼ 全ステップ（横20 / ショート14）の詳細を見る クリックで開閉

⚙️ 慣れてきた方や、 各ステップの中身を確認したい方向け。 ふだんは AI が自動で次のコマンドを案内するので、 ここを読まなくても動画は完成します。

PHASE 1 / 素材準備
  • /step01-context 「誰に向けた、 どんな動画か？」 を整理。 AI が質問してくれるので答えるだけ
  • /step02-assets 動画ファイルを所定のフォルダに置く案内。 AI が「これは本編、 これは差し込み用」 と自動で仕分け
  • /step03-transcript 動画の話してる内容を AI が文字起こし。 1単語ごとに「何秒のセリフか」 まで記録（テロップに使います）
  • /step04-transcript-fix 文字起こしの誤字をチェック。 用意した台本があれば自動で照合してくれます（人名・数字を重点的に）
  • /step05-cut 無音 + 「えーと」 + 言い直しを一括カット。 同じことを何度も言い直しても、 一番きれいに言えた最後の1回だけ残してくれます
  • /step06-transcript カット後の動画でもう一度文字起こし（次の工程で使う最新の状態に更新）
PHASE 2 / 動画構築
  • /step07-template ブラウザで好きなデザインを選ぶだけ。 テロップの色・フォント・効果音・アニメーションを画面上で確認しながらクリックで決定
  • /step08-telop AI が話の内容に合わせて テロップを自動配置。 強調したい部分・否定の部分・引用などを判断して、 8種類のスタイルから自動で振り分け
  • /step09-composition 動画 + テロップ + 効果音を組み立てて ブラウザでプレビュー。 メイン動画にズームインや軽いボカシなどの動きも自動で適用
PHASE 3 / 素材・演出挿入（必要なものだけ）
  • /step10-greenback 任意 グリーンバックで撮った動画の 背景を好きな画像・動画に差し替え。 緑の縁取りも自動でキレイに除去
  • /step11-videos 任意 デモ動画やスクショ動画を差し込み。 「本編に切り込む」 か「上に重ねる」 か選べます
  • /step12-slides-gen 任意・横のみ 台本を渡すと AI が スライドを自動生成。 構成・デザインも全部おまかせ
  • /step13-slides 任意・横のみ step12 で作ったスライドを動画の該当箇所に自動で挿入
  • /step14-wipe 任意・横のみ 顔出し小窓（ワイプ）の位置・大きさを調整。 「右下に少し小さめ」 など好みで
  • /step15-images 任意 画像を差し込み。 手持ちの画像でも、 AIに「○○の画像作って」 と頼んで生成 もOK
  • /step16-special-components 任意・横のみ 箇条書き・大きな見出し・最後のCTAボタンなど、 動画の中で目立たせたい部品を追加
  • /step17-op-ed 任意・横のみ OP（オープニング動画）と ED（エンディング動画）を本編にくっつけて、 1本につなげる
PHASE 4 / BGM・出力
  • /step18-bgm BGMを挿入。 動画の始まり・終わりは自動でフェード、 BGMが動画より短ければ自動でループ再生
  • /step19-render 完成版の動画を MP4ファイルとして書き出し。 待っている間にコーヒーでも
  • /step20-highlight-final 本編から ハイライト動画を自動抽出（金色の縁取り + 額縁デザイン付き）。 音量も YouTube 標準に自動調整 → 完成 🎉

🔁2本目以降の動画を作る方へ

Step 01〜04 はスキップしてOK。1本目のプロジェクト内で動いている Claude Code セッションで、 以下のコマンドを打つだけで新しい動画が作れます:

/new-video

プロジェクト名と動画タイプ（横 / ショート）を聞かれた後、 そのまま AUTO_RUN モードで step01 から進行します。 Step 05 を参考に素材を配置してください。

自動で引き継がれるもの:

  • ✅ ツール類（git / node / ffmpeg / gh / claude-code / python@3.12）— 再インストール不要
  • ✅ naoki-blueprint 本体 — 再ダウンロード不要
  • ✅ ライセンス（新規プロジェクトに自動コピー、再認証不要）

※ Claude Code を閉じてしまった場合: cd naoki-blueprint && claude --dangerously-skip-permissions で起動して /new-video から始めてください。
