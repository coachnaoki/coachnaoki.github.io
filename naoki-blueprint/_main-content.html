01事前準備（3つだけ）

動画制作を始める前に、 以下の 3 つを済ませてください。 どれも 5 分以内で終わります。

① このページをブックマーク

ライセンスIDを忘れた時にいつでも再表示できます。 Mac は Cmd + D、 Windows は Ctrl + D でブックマーク追加。

② Chatwork で Naoki を追加

サポート・ご質問の窓口です。 困ったらいつでも Chatwork でメッセージしてください。

Chatwork で Naoki を追加

③ GitHub からの招待メールを承認

同意書送信後に GitHub から「Invitation to coach-naoki/naoki-blueprint」 という件名のメール / GitHub 通知が届きます。 メール内の 「View invitation」 → 「Accept」 をクリック。

📌 招待 Accept をしないとリポジトリを取得 (Step 03) できません。 必ず最初に Accept してください。

02リポジトリ取得

準備を始めましょう。

① まず、 naoki-blueprint を置く専用フォルダを作成

Finder (Mac) / エクスプローラ (Win) で、 動画制作用の空フォルダを好きな場所に作ります (例: フォルダ名「video」 / 場所はデスクトップでも書類でも OK)。

② そのフォルダのパスをコピー

  • Mac: Finder でフォルダを右クリック → 「option」 キーを押すとメニューが切り替わる → 「"video" のパス名をコピー」
  • Windows: エクスプローラで作成したフォルダを開く → 上部のアドレスバーをクリックするとパス (例: C:\Users\…\video) が表示される → 選択してコピー

③ ターミナル (Cursor 下部) で cd の後ろにコピーしたパスを貼り付け

⚠ 下の例はそのままコピペしない。 cd (cd の後ろに半角スペース) を打ってから、 ②でコピーしたパスを貼り付けて Enter。

例 (Mac でデスクトップに video を作った人の場合):

cd /Users/<ユーザー名>/Desktop/video

④ リポジトリをダウンロード（Mac / Windows 共通・このコマンドはそのままコピペでOK）:

git clone https://github.com/coach-naoki/naoki-blueprint.git

⑤ ダウンロードしたフォルダに入る（このコマンドもそのままコピペでOK）:

cd naoki-blueprint

03Claude Code を起動して動画作成開始

① Claude Code を起動（Mac / Windows 共通）:

claude --dangerously-skip-permissions

② Claude Code 内で /new-video を実行:

/new-video

📌 初回のみ: /new-video を実行するとライセンスコード (例: NK-XXXX-XXXX-XXXX) の入力を求められます。 このページの下部に表示されているライセンスIDをコピーして貼り付けてください。

起動すると、以下を順に聞かれます:

  1. 動画タイプ (横動画 / ショート動画)
  2. プロジェクト名（日付でOK。例: 2026-04-19）
  3. オートモード (途中の確認をスキップして一気に進めるか)
  4. 対談動画かどうか (インタビュー / 対談ならインタビュアーとインタビュイーで字幕色を分けます)

04素材を配置 → 作業開始

📂 step02 (素材確認) に入った瞬間に public/ フォルダが自動で開きます
Finder (Mac) / エクスプローラー (Win) で public/ が開くので、 以下のフォルダ構成を参考に素材をドラッグ＆ドロップしてください。 配置できたら Claude Code に 「配置完了」 と返答すれば残りの step が自動で進みます。

フォルダ構成 (projects/<プロジェクト名>/public/):

public/ ├── videos/ 動画素材 │ ├── main/ 本編動画 ★必須 │ ├── inserts/ 物理挿入動画（任意） │ ├── overlays/ オーバーレイ動画（任意） │ ├── opening/ OP動画（横動画のみ・任意） │ └── highlight/ ハイライト動画（自動生成・横動画のみ） ├── images/ 画像素材 │ ├── inserts/ 横に表示する画像（任意） │ ├── overlays/ 全画面表示画像・アニメーション付（任意） │ └── icon/ 話者アイコン・対談動画用（任意） ├── bgm/ BGM（MP3） ★必須 ├── se/ SE効果音 ★必須 │ ├── 強調/ │ ├── ポジティブ/ │ └── ネガティブ/ ├── script/ ナレーション台本（推奨） └── output/ 完成動画の出力先

💡 SE / BGM をまだ持っていない方へ

Naoki が実際に使っている SE / BGM の推奨リスト を共有しています。 配布元サイト・楽曲名・利用シーン (強調 / ポジティブ / ネガティブ) でフィルタできます。
👉 SE / BGM 推奨リスト (Google Sheets)

素材を置いたら Claude Code で「素材配置完了」 等と返答すれば AUTO_RUN が再開します。 あとは AI が次のコマンドを案内してくれるので、質問に答えながら進めるだけ。

🎬ワークフロー詳細（横動画 全20 step / ショート 全14 step）

各ステップは Claude Code でスラッシュコマンド1つで実行できます。任意 とあるステップは必要な演出だけ使えばOK。基本は AI が次のコマンドを案内してくれるので、順番通りに進めるだけで完成します。

PHASE 1 / 素材準備
  • /step01-context 動画の目的・ターゲット・視聴者像を整理
  • /step02-assets 素材確認（本編/物理挿入/オーバーレイ/OP/ハイライト）とFPS自動検出
  • /step03-transcript 本編を mlx-whisper-large-v3 で文字起こし（word-level timestamps・ローカル実行で API キー不要）
  • /step04-transcript-fix 台本と照合して誤変換を修正（固有名詞・数字を重点チェック）
  • /step05-cut 無音 + 言い直しを一括カット。 N-gram 重複検出で複数回言い直しても最後の発話を残す (v2.5.3+)
  • /step06-transcript カット後の再文字起こし + 修正再適用
PHASE 2 / 動画構築
  • /step07-template テンプレート設定。 picker UI (v2.5+) で各テンプレのカラー・フォント・SE・アニメーションを GUI で選択 (localhost:5174)
  • /step08-telop テロップデータ作成。 AI が 8 種のスタイル（normal/emphasis/negative等）から自動判定 + 字幕カバー率 90% ルール
  • /step09-composition MainComposition.tsx で動画 + テロップ + SE を統合。 Remotion Studio がブラウザで起動（localhost:3000）+ メイン動画アニメ (zoom_in / zoom_out / blur) 適用
PHASE 3 / 素材・演出挿入（任意）
  • /step10-greenback 任意 グリーンバック背景置換。chromakey + rembg + HSV despill の3段パイプライン
  • /step11-videos 任意 デモ動画挿入（物理挿入=Series分割 / オーバーレイ=上に重ね）
  • /step12-slides-gen 任意・横のみ 台本からスライドHTMLを生成
  • /step13-slides 任意・横のみ スライドキャプチャ + タイムライン配置
  • /step14-wipe 任意・横のみ ワイプ（顔出し）位置をピクセル座標で調整
  • /step15-images 任意 画像挿入 + AI 生成 (Gemini) を 1 step に統合 (v2.5.5+)。 顔アイコン (Phase 3) のみ別途確認
  • /step16-special-components 任意・横のみ 箇条書き・見出しバナー・CTAコンポーネント
  • /step17-op-ed 任意・横のみ OP / ED 連結 + Composition "Final" 組み立て (Series 構造)
PHASE 4 / BGM・出力
  • /step18-bgm BGM挿入（フェードイン/アウト付き、区間・音量指定可、不足時は自動ループ）
  • /step19-render 本編レンダリング (Composition "Final" or MainComposition を MP4 書き出し)
  • /step20-highlight-final 本編からハイライト自動抽出 + 0.9 倍縮小 + 金縁 + 深紺額縁 (v2.5.4+) + ラウドネス正規化 -14 LUFS + 最終レンダリング → 完成 🎉

縦動画用テンプレート。 情報密度を優先し、 横動画よりシンプル構成。 スライド・ワイプ・特殊コンポ・OP/ED・ハイライトは含まれません。

PHASE 1 / 素材準備
  • /step01-context 動画の目的・ターゲット・視聴者像を整理
  • /step02-assets 素材確認 (本編 / 物理挿入 / オーバーレイ) と FPS 自動検出
  • /step03-transcript 本編を mlx-whisper-large-v3 で文字起こし (word-level timestamps・ローカル実行で API キー不要)
  • /step04-transcript-fix 台本と照合して誤変換を修正 (固有名詞・数字を重点チェック)
  • /step05-cut 無音 + 言い直しを一括カット。 N-gram 重複検出で複数回言い直しても最後の発話を残す
  • /step06-transcript カット後の再文字起こし + 修正再適用
PHASE 2 / 動画構築
  • /step07-template テンプレート設定 (picker UI でカラー・フォント・SE・アニメーションを選択)
  • /step08-telop テロップデータ作成 (8 種のスタイルから AI が自動判定)
  • /step09-composition MainComposition.tsx で動画 + テロップ + SE を統合 + メイン動画アニメ (zoom_in / zoom_out / blur) 適用
PHASE 3 / 素材挿入 (任意)
  • /step10-greenback 任意 グリーンバック背景置換
  • /step11-videos 任意 デモ動画挿入 (物理挿入 = Series 分割 / オーバーレイ = 上に重ね)

  • /step14-final 1080×1920 で最終レンダリング + ラウドネス正規化 -14 LUFS → 完成 🎉
💡 便利コマンド: /catchup で現在の進捗を確認できます。中断しても AI がどのステップから再開すべきか教えてくれるので、気軽に休憩OK。

🔁2本目以降の動画を作る方へ

Step 01〜04 はスキップしてOK。1本目のプロジェクト内で動いている Claude Code セッションで、 以下のコマンドを打つだけで新しい動画が作れます:

/new-video

プロジェクト名と動画タイプ（横 / ショート）を聞かれた後、 そのまま AUTO_RUN モードで step01 から進行します。 Step 05 を参考に素材を配置してください。

自動で引き継がれるもの:

  • ✅ ツール類（git / node / ffmpeg / gh / claude-code / python@3.12 + Whisper）— 再インストール不要
  • ✅ naoki-blueprint 本体 — 再ダウンロード不要
  • ✅ ライセンス（新規プロジェクトに自動コピー、再認証不要）

※ Claude Code を閉じてしまった場合: cd naoki-blueprint && claude --dangerously-skip-permissions で起動して /new-video から始めてください。
