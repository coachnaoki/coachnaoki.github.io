ライセンスIDを忘れた時にいつでも再表示できます。 Mac は Cmd + D、 Windows は Ctrl + D でブックマーク追加。

② Chatwork で Naoki を追加

Chatwork で Naoki を追加

③ GitHub からの招待メールを承認

同意書送信後に GitHub から「Invitation to coach-naoki/naoki-blueprint」 という件名のメール / GitHub 通知が届きます。 メール内の 「View invitation」 → 「Accept」 をクリック。

02環境セットアップ（初回のみ）

動画制作に必要なツールをインストールします。 すでに入っているものはスキップ OK。 所要時間 5-10 分。

macOS

① 全ツールを 1 行でインストール (Homebrew + Git/Node/FFmpeg/GitHub CLI/Python 3.12/Claude Code/Whisper まで全部)

ターミナル (Cursor 下部) で以下を実行:

[ -x /opt/homebrew/bin/brew ] || /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && eval "$(/opt/homebrew/bin/brew shellenv)" && brew install git node ffmpeg gh python@3.12 && brew install --cask claude-code@latest && /opt/homebrew/bin/pip3.12 install mlx-whisper --break-system-packages

※ 先頭の [ -x /opt/homebrew/bin/brew ] || ... は 「Homebrew が無ければインストール / あればスキップ」 の自動判定です。 既に Homebrew がある人は最初の行が一瞬で skip して、 ツール install からすぐ始まります。

※ Homebrew 新規インストール時は Mac のログインパスワードと RETURN キー押下を求められます (入力中はパスワード非表示)。 5-15 分かかります。 完了したら Cursor を一度閉じて再起動 (PATH 反映のため)。

※ 初回の /step03-transcript 実行時に Whisper モデル (約 3GB) が自動 DL されます (5-10 分)。 2 回目以降はキャッシュで高速。

② GitHub にログイン

gh auth login

プロンプトに従って:

  • What account do you want to log into? → GitHub.com
  • What is your preferred protocol? → HTTPS
  • Authenticate Git with your GitHub credentials? → Y
  • How would you like to authenticate? → Login with a web browser
  • 表示された 8 桁コードをブラウザに入力 → 認証完了 (1 分)

③ インストール確認

git --version && node --version && gh --version && claude --version && /opt/homebrew/bin/python3.12 --version && /opt/homebrew/bin/python3.12 -c "import mlx_whisper; print('whisper OK')"

5 つのバージョン番号 + whisper OK が表示されれば成功。 1 つでも「command not found」 や Python エラーが出る場合は Cursor を再起動して再度実行してください。

Windows

① 全ツールを 1 行でインストール

Git / Node.js / FFmpeg / GitHub CLI / Python 3.12 / Claude Code / Whisper (文字起こし AI) をまとめて入れます。 PowerShell (Cursor 下部) で以下を実行:

winget install --id Git.Git -e; winget install OpenJS.NodeJS.LTS; winget install Gyan.FFmpeg; winget install GitHub.cli; winget install Anthropic.ClaudeCode; winget install Python.Python.3.12 -e; $env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User"); py -3.12 -m pip install faster-whisper

※ 5-10 分かかります。 $env:Path = ... の部分は winget で入れた Python の PATH を即座に反映するための呪文 (これがないと最後の py -3.12 が見つからない)。 完了したら Cursor を完全に閉じて再起動。

※ 初回の /step03-transcript 実行時に Whisper モデル (約 3GB) が自動 DL されます (5-10 分)。 2 回目以降はキャッシュで高速。

⚠ 「winget は認識されていません」 と出る場合: Microsoft Store から「アプリ インストーラー」 を更新してください。

② GitHub にログイン

gh auth login

macOS と同じく、 GitHub.com → HTTPS → Login with a web browser で認証 (1 分)。

③ インストール確認

git --version; node --version; gh --version; claude --version; py -3.12 --version; py -3.12 -c "import faster_whisper; print('whisper OK')"

5 つのバージョン番号 + whisper OK が表示されれば成功。 「node は認識されていません」 等が出る場合: Cursor を完全に閉じて再起動。 それでもダメなら PC を再起動。

03リポジトリ取得

準備を始めましょう。

① まず、 naoki-blueprint を置く専用フォルダを作成

Finder (Mac) / エクスプローラ (Win) で、 動画制作用の空フォルダを好きな場所に作ります (例: フォルダ名「video」 / 場所はデスクトップでも書類でも OK)。

② そのフォルダのパスをコピー

  • Mac: Finder でフォルダを右クリック → 「option」 キーを押すとメニューが切り替わる → 「"video" のパス名をコピー」
  • Windows: エクスプローラで作成したフォルダを開く → 上部のアドレスバーをクリックするとパス (例: C:\Users\…\video) が表示される → 選択してコピー

③ ターミナル (Cursor 下部) で cd の後ろにコピーしたパスを貼り付け

⚠ 下の例はそのままコピペしない。 cd (cd の後ろに半角スペース) を打ってから、 ②でコピーしたパスを貼り付けて Enter。

例 (Mac でデスクトップに video を作った人の場合):

cd /Users/<ユーザー名>/Desktop/video

④ リポジトリをダウンロード（Mac / Windows 共通・このコマンドはそのままコピペでOK）:

git clone https://github.com/coach-naoki/naoki-blueprint.git

⑤ ダウンロードしたフォルダに入る（このコマンドもそのままコピペでOK）:

cd naoki-blueprint

プロジェクト作成 → npm install → AUTO_RUN モードで step01〜 が自動進行します。 途中でライセンス認証 (Step 03) が自動誘導されます。

05素材を配置 → 作業開始

素材を projects/<プロジェクト名>/public/ に配置（Finder / エクスプローラーからドラッグ＆ドロップでOK）:

public/ ├── videos/ 動画素材 │ ├── main/ 本編動画 ★必須 │ ├── inserts/ 物理挿入動画（任意） │ ├── overlays/ オーバーレイ動画（任意） │ ├── opening/ OP動画（横動画のみ・任意） │ └── highlight/ ハイライト動画（自動生成・横動画のみ） ├── images/ 画像素材 │ ├── inserts/ 横に表示する画像（任意） │ └── overlays/ 全画面表示画像・アニメーション付（任意） ├── bgm/ BGM（MP3） ★必須 ├── se/ SE効果音 ★必須 │ ├── 強調/ │ ├── ポジティブ/ │ └── ネガティブ/ ├── script/ ナレーション台本（推奨） └── output/ 完成動画の出力先

💡 SE / BGM をまだ持っていない方へ

Naoki が実際に使っている SE / BGM の推奨リスト を共有しています。 配布元サイト・楽曲名・利用シーン (強調 / ポジティブ / ネガティブ) でフィルタできます。
👉 SE / BGM 推奨リスト (Google Sheets)

素材を置いたら Claude Code で「素材配置完了」 等と返答すれば AUTO_RUN が再開します。 あとは AI が次のコマンドを案内してくれるので、質問に答えながら進めるだけ。

🎬ワークフロー詳細（横動画 全20 step / ショート 全14 step）

各ステップは Claude Code でスラッシュコマンド1つで実行できます。任意 とあるステップは必要な演出だけ使えばOK。基本は AI が次のコマンドを案内してくれるので、順番通りに進めるだけで完成します。

PHASE 1 / 素材準備
  • /step01-context 動画の目的・ターゲット・視聴者像を整理
  • /step02-assets 素材確認（本編/物理挿入/オーバーレイ/OP/ハイライト）とFPS自動検出
  • /step03-transcript 本編を mlx-whisper-large-v3 で文字起こし（word-level timestamps・ローカル実行で API キー不要）
  • /step04-transcript-fix 台本と照合して誤変換を修正（固有名詞・数字を重点チェック）
  • /step05-cut 無音 + 言い直しを一括カット。 N-gram 重複検出で複数回言い直しても最後の発話を残す (v2.5.3+)
  • /step06-transcript カット後の再文字起こし + 修正再適用
PHASE 2 / 動画構築
  • /step07-template テンプレート設定。 picker UI (v2.5+) で各テンプレのカラー・フォント・SE・アニメーションを GUI で選択 (localhost:5174)
  • /step08-telop テロップデータ作成。 AI が 8 種のスタイル（normal/emphasis/negative等）から自動判定 + 字幕カバー率 90% ルール
  • /step09-composition MainComposition.tsx で動画 + テロップ + SE を統合。 Remotion Studio がブラウザで起動（localhost:3000）+ メイン動画アニメ (zoom_in / zoom_out / blur) 適用
PHASE 3 / 素材・演出挿入（任意）
  • /step10-greenback 任意 グリーンバック背景置換。chromakey + rembg + HSV despill の3段パイプライン
  • /step11-videos 任意 デモ動画挿入（物理挿入=Series分割 / オーバーレイ=上に重ね）
  • /step12-slides-gen 任意・横のみ 台本からスライドHTMLを生成
  • /step13-slides 任意・横のみ スライドキャプチャ + タイムライン配置
  • /step14-wipe 任意・横のみ ワイプ（顔出し）位置をピクセル座標で調整
  • /step15-images 任意 画像挿入 + AI 生成 (Gemini) を 1 step に統合 (v2.5.5+)。 顔アイコン (Phase 3) のみ別途確認
  • /step16-special-components 任意・横のみ 箇条書き・見出しバナー・CTAコンポーネント
  • /step17-op-ed 任意・横のみ OP / ED 連結 + Composition "Final" 組み立て (Series 構造)
PHASE 4 / BGM・出力
  • /step18-bgm BGM挿入（フェードイン/アウト付き、区間・音量指定可、不足時は自動ループ）
  • /step19-render 本編レンダリング (Composition "Final" or MainComposition を MP4 書き出し)
  • /step20-highlight-final 本編からハイライト自動抽出 + 0.9 倍縮小 + 金縁 + 深紺額縁 (v2.5.4+) + ラウドネス正規化 -14 LUFS + 最終レンダリング → 完成 🎉

🆘困った時のトラブルシューティング

インストール中によくある詰まりポイントと対処法をまとめました。 該当する症状を探して対処してください。

🔧 Mac / Windows 共通

❓ 「command not found」 系のエラーが出る

→ Cursor を 完全に閉じて再起動 してください。 環境変数 (PATH) はインストール後に Cursor を開き直さないと反映されません。 それでもダメなら PC 自体を再起動。

❓ git clone で 「Permission denied」 「could not access」 のエラー

→ GitHub からの招待メール (件名 「Invitation to coach-naoki/naoki-blueprint」) を Accept していますか? 受信ボックス・迷惑メールを確認 → 「View invitation」 → 「Accept」 をクリックしてから再実行してください。

❓ 5 分以上経っても何も表示されず止まって見える

→ Whisper モデル (約 3GB) のダウンロード中の可能性があります。 進捗バーが見えなくても裏で動いています。 10-15 分は待ってみてください (回線速度次第)。

❓ gh auth login のブラウザが自動で開かない

→ ターミナルに表示された URL を手動でコピーしてブラウザに貼り付け、 表示された 8 桁コードを入力してください。 URL が改行で折り返されている場合は、 改行を含めず 1 行として全部コピーするのがコツ。

❓ GitHub の招待メールが届かない

→ ① 迷惑メールフォルダを確認 ② 同意書で入力した GitHub username が普段ログインしているアカウントと一致しているか確認 ③ GitHub の招待ページ に直接アクセスして Accept する手も使えます。

🍎 macOS

❓ パスワードを入力しても何も表示されない

→ これは仕様です。 セキュリティのため Mac ではパスワード入力中の文字は画面に表示されません。 そのまま入力して Enter キーを押せば進みます。

❓ Homebrew のインストールに 15 分以上かかる

→ 初回インストール時は Xcode Command Line Tools の DL も含むため最大 20 分かかることがあります。 進行中であれば待つのが正解。 完全に止まっていそうなら Cursor を再起動して再実行。

🪟 Windows

❓ 「winget は内部コマンドまたは外部コマンド・・・として認識されません」

→ Microsoft Store を開き、 検索欄で「アプリ インストーラー」 を検索 → 「更新」 ボタンをクリック。 更新完了後、 PowerShell を開き直して再実行してください。

❓ 「py -3.12 は認識されません」 が最後だけ出る

→ PATH 反映の呪文 ($env:Path = ...) が正しくコピーされなかった可能性。 改行が混ざらないように、 Step 02 ① のコマンド全体を 1 行として コピーして再実行してください。 それでもダメなら Cursor を完全に閉じて再起動。

❓ 「実行ポリシーによりこのスクリプトは実行できません」

→ PowerShell で以下を実行: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned (Y を押して許可) してから再実行。

それでも解決しない場合は Chatwork で Naoki に連絡 してください。 エラーメッセージのスクショを添えて送ると早く解決できます。
