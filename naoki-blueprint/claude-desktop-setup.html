Naoki's Blueprint / Setup

Claude Code セットアップガイド

Claude Code デスクトップアプリを使った環境構築。セットアップ完了まで 30〜60 分。

🧪 テスト版 — Cursor版セットアップガイドの代替案として検証中
💡 Cursor版との違い
  • Cursorエディタの代わりに Claude Code デスクトップアプリ（シンプルなAIターミナル）を使います
  • 複雑なエディタ画面がなく、AIとの会話だけで動画が完成します
  • 必要なツール（Git / Node.js 等）のインストールは同じです
  • 料金: Claude Pro ($20/月〜) — Cursor Pro ($20/月) と同額
🍎 Mac 版 🪟 Windows 版

01Anthropic アカウントを作成

⏱ 所要時間: 3〜5分🎯 ゴール: Claude Pro プランに加入した状態

Claude Code を使うには Anthropic のアカウントと Claude Pro プラン以上 ($20/月〜) が必要です。

手順

  1. https://claude.ai/ にアクセス
  2. 「Sign up」からアカウントを作成（Google アカウントでもメールアドレスでも OK）
  3. ログイン後、左下の「Upgrade to Pro」をクリック → Pro プラン以上 ($20/月〜) に加入
💡 すでに Claude アカウントをお持ちの方
Pro プラン以上に加入済みであれば、このステップはスキップしてください。

02Claude Code をインストール

⏱ 所要時間: 3〜5分🎯 ゴール: Claude Code デスクトップアプリが起動した状態

Claude Code は AI と会話しながら作業できるアプリ です。Cursor のような複雑なエディタ画面はありません。AI に「テロップを入れて」「BGMを追加して」と日本語で指示するだけです。

手順

  1. https://claude.ai/download にアクセス
  2. 「Claude Code」のダウンロードボタンをクリック（Mac 版）
  3. ダウンロードした .dmg ファイルをダブルクリック
  4. 「Claude Code」アイコンを「Applications」フォルダにドラッグ
  5. Launchpad から Claude Code を起動
  6. Anthropic アカウントでログイン
⚠ エラー: 「"Claude Code" は開発元を検証できないため開けません」
通常は表示されませんが、もし出たら:
システム設定 → プライバシーとセキュリティ → 下にスクロール → 「このまま開く」 をクリック。

03環境セットアップ（初回のみ）

⏱ 所要時間: 5〜15分🎯 ゴール: 動画制作に必要なツール (Git / Node.js / FFmpeg / GitHub CLI / Python) が全部入った状態

動画を作るために必要な裏方のツールを入れます。1 行のコマンドで全部まとめてインストールできます。

① ターミナルを開く

Mac の「ターミナル」アプリを開きます（Launchpad → 「その他」フォルダ、または Spotlight で「ターミナル」と検索）。

② 全ツールを 1 行でインストール

ターミナルで以下のコマンドをコピペして Enter:

[ -x /opt/homebrew/bin/brew ] || /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && eval "$(/opt/homebrew/bin/brew shellenv)" && brew install git node ffmpeg gh python@3.12

③ GitHub にログイン

ターミナルで以下を実行:

gh auth login

プロンプトに従って:

  • What account do you want to log into? → GitHub.com
  • What is your preferred protocol? → HTTPS
  • Authenticate Git with your GitHub credentials? → Y
  • How would you like to authenticate? → Login with a web browser
  • 表示された 8 桁コードをブラウザに入力 → 認証完了 (1 分)

④ インストール確認

ターミナルで以下を実行:

git --version && node --version && ffmpeg -version && gh --version && /opt/homebrew/bin/python3.12 --version

5 つのバージョン番号が表示されれば成功。

⑤ naoki-blueprint をダウンロード

ターミナルで以下を実行:

cd ~/Desktop && git clone https://github.com/coach-naoki/naoki-blueprint.git

デスクトップに「naoki-blueprint」フォルダが作られます。

💡 Claude Code アプリの再起動
Step 02 で Claude Code を先に起動していた場合は、ここでアプリを完全に終了してから再起動してください。
インストールしたツール（Git / Node.js 等）を Claude Code に認識させるために必要です。

04Claude Code でプロジェクトを開く

⏱ 所要時間: 3〜5分🎯 ゴール: Claude Code 内で naoki-blueprint が開いた状態

手順

  1. Claude Code デスクトップアプリを起動（または再起動後に開く）
  2. 上部の「Code」タブをクリック
  3. 「Local」を選択
  4. 「Select folder」をクリック → デスクトップの naoki-blueprint フォルダを選択
💡 Permission（権限モード）の設定
初回起動時に権限モードを聞かれたら「Auto accept edits」を選択してください。
Claude がファイルの編集・コマンド実行を自動で行えるようになり、毎回の確認が不要になります。
（後から Claude Code の設定画面で変更できます）

05動画作成を開始

⏱ 所要時間: 1 分🎯 ゴール: /new-video が動いた状態

手順

  1. Claude Code のチャット欄に以下を入力して送信:
/new-video
  1. 初回はライセンスコード (例: NK-XXXX-XXXX-XXXX) の入力を求められます。
    インストールガイドのページ下部に表示されているライセンスIDをコピーして貼り付けてください。
  2. あとは Claude の質問に答えていくだけで動画が完成します 🎉

✓セットアップ完了!

これで Claude Code + 環境ツールがすべて動く状態になりました。

Cursor と違い、エディタの操作を覚える必要はありません。
Claude に日本語で指示するだけで動画が作れます。

03環境セットアップ（初回のみ）

⏱ 所要時間: 5〜15分🎯 ゴール: 動画制作に必要なツール (Git / Node.js / FFmpeg / GitHub CLI / Python) が全部入った状態

動画を作るために必要な裏方のツールを入れます。1 行のコマンドで全部まとめてインストールできます。

① PowerShell を開く

スタートメニューで「PowerShell」と検索 → 「Windows PowerShell」を開きます。

② 全ツールを 1 行でインストール

PowerShell で以下のコマンドをコピペして Enter:

winget install --id Git.Git -e --source winget; winget install OpenJS.NodeJS.LTS --source winget; winget install Gyan.FFmpeg --source winget; winget install GitHub.cli --source winget; winget install Python.Python.3.12 -e --source winget; $env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User"); if (Test-Path "$env:ProgramFiles\Git\cmd") { $env:Path += ";$env:ProgramFiles\Git\cmd" }
💡 インストール後は PowerShell を一度閉じて開き直してください。
ツールの PATH（= コマンドの場所）が正しく反映されます。

③ GitHub にログイン

PowerShell で以下を実行:

gh auth login

プロンプトに従って:

  • What account do you want to log into? → GitHub.com
  • What is your preferred protocol? → HTTPS
  • Authenticate Git with your GitHub credentials? → Y
  • How would you like to authenticate? → Login with a web browser
  • 表示された 8 桁コードをブラウザに入力 → 認証完了 (1 分)

④ インストール確認

PowerShell で以下を実行:

git --version; node --version; ffmpeg -version; gh --version; py -3.12 --version

5 つのバージョン番号が表示されれば成功。

⚠ 「git : 用語 'git' は〜認識されません」 と出る場合
PATH が反映されていません。PowerShell を閉じて → 開き直してから ④ を再実行してください。
それでもダメな場合は、以下を実行してから再度確認:
winget install --id Git.Git -e --source winget

⑤ naoki-blueprint をダウンロード

PowerShell で以下を実行:

cd ~\Desktop; git clone https://github.com/coach-naoki/naoki-blueprint.git

デスクトップに「naoki-blueprint」フォルダが作られます。

💡 Claude Code アプリの再起動
Step 02 で Claude Code を先に起動していた場合は、ここでアプリを完全に終了してから再起動してください。
インストールしたツール（Git / Node.js 等）を Claude Code に認識させるために必要です。
