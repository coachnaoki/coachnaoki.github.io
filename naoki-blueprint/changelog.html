v2.13.0 2026-05-14 文字起こし刷新
🎙️ 文字起こし ASR を Speechmatics standard に完全移行

旧 mlx-whisper / faster-whisper は smoothing で「言い直し」が消えるため picker-cut の検出が機能していなかった (9 分動画で 1 件しか拾えず実用不可)。 Speechmatics standard に完全移行することで、 phrase 認識完全性と言い直し検出件数の両方で Deepgram を上回る結果に。

  • 無料枠 8 時間/月 (超過時 $0.204/時 = ¥31/時)
  • 動画 → 16kHz mono mp3 軽量化を内蔵 (1GB → 数 MB に圧縮)
  • Python + Whisper 環境が不要に (Mac mlx-whisper / Win faster-whisper のインストール手順が消える)
  • API キー登録: .env ファイルに SPEECHMATICS_API_KEY= を直接記載 (チャットにキーを貼らせない流儀)
  • 句読点抑止 で picker-cut の N-gram 検出が素直に動くように
