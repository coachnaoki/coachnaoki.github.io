v2.7.0 2026-05-04 文字起こし精度向上
🎙️ 文字起こし AssemblyAI → mlx-whisper-large-v3 に復帰

v2.4 〜 v2.6 で採用していた AssemblyAI Universal-2 を廃止し、 mlx-whisper-large-v3 (Mac) / faster-whisper-large-v3 (Win) に復帰。 受講生のショート動画で精度低下事例が多発したため差し戻し。 ローカル実行のため API キー不要・追加費用なし。

  • 初回セットアップ (v2.6 以前の方): Mac → brew install python@3.12 && /opt/homebrew/bin/pip3.12 install mlx-whisper / Win → winget install Python.Python.3.12; py -3.12 -m pip install faster-whisper
  • 初回実行で Whisper モデル (約 3GB) が自動 DL (5-10 分)。 2 回目以降はキャッシュ
  • .env の ASSEMBLYAI_API_KEY=... 行は不要 (残っていても無視される)
📐 ショート動画の文字数制限 1080px 幅に厳格化

ショート動画 (1080×1920 縦) で横動画と同じ文字数を入れて画面外にはみ出す事故が頻発していたため、 1080px 幅に合わせて 文字数 を絞り込み。 旧 20字 / 14字 → 新 11字 / 8字 (fontSize 84 / 122 の場合)。

  • fontSize 84 (normal/normal_emphasis): 20字 → 11字
  • fontSize 84 third_party (通常モード): 18字 → 9字 (｢ ｣ 占有 +2)
  • fontSize 108 (theme): 16字 → 9字
  • fontSize 122 (emphasis 系): 14字 → 8字
✂️ 改行ルール: 単語の途中で切らない

テロップ分割位置は 助詞 (は/の/に/を/が/で/も/て/と) の後 / 動詞活用語尾の後 / 名詞境界 で切る。 「ボ│レーが」 「ストレ│ートを」 のように単語の途中で切る分割は禁止。

🎤 対談動画モード (dialogVideo) + interviewee テンプレ追加

step01-context で「対談 / インタビュー動画ですか？」 を確認。 対談動画モード時は transcript を内容分析して インタビュアー (発信者) / インタビュイー (ゲスト) を自動分類し、 ゲストには新テンプレ interviewee (teal 色・normal と同型 SVG) を適用。

  • 新テンプレ interviewee: NORMAL_VARIANTS の cyan variant (teal 系) で normal (紺) と視覚区別。 対談 / インタビュー動画でゲストの発話に使う
  • 新テンプレ interviewee_emphasis: normal_emphasis のインタビュイー版 (teal ベース + 赤強調)。 ゲストの 1 語強調でもベース色が teal で維持される
  • インタビュアー (発信者・質問する側): normal / normal_emphasis (紺) をそのまま使用。 チャンネルの顔は既存色で統一
  • 判定アルゴリズム: 質問パターン (?, ですか, 教えてください) / 紹介パターン (お越しいただきました) / 短い相槌 (なるほど) → インタビュアー。 該当しない長めの発話 → インタビュイー
  • third_party の ｢｣ 自動付与は OFF にしない: 対談動画でも視聴者の声を引用する場面で従来通り使用
⏱ テロップを Sequence でラップ (Studio タイムライン表示対応)

全テロップを <Sequence> でラップする運用に変更。 Remotion Studio の左下タイムラインに 1 テロップ = 1 ブロックとして並び、 視覚的にスクラブ・ドラッグ確認できるように。

🔒 インフラ: 凍結リポを Private 化 + Pages を User Page repo に移行

v2.5.5 凍結 Public リポを Private 化してテンプレ漏洩リスクを完全排除。 Pages は coachnaoki/coachnaoki.github.io (User Page・docs only) から配信に切替。 URL は変わらず維持 (ブックマーク・SNS シェアそのまま)。

v2.5.3 2026-05-03 v2.5 系
🎯 N-gram 言い直し検出「最後の発話を残す」 ルール確立

v2.4.0〜v2.5.2 で同一フレーズが 2 回以上繰り返されると、 サブセット phrase の重複検出 + merge により 2 回目の発話冒頭まで食い込んでカットされていた問題を修正。

  • サブセット phrase 重複排除: 長い N から降順処理し、 同一言い直し箇所が 1 つにまとまる
