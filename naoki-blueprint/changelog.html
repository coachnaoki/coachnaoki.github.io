📐 ショート動画の文字数制限 1080px 幅に厳格化

ショート動画 (1080×1920 縦) で横動画と同じ文字数を入れて画面外にはみ出す事故が頻発していたため、 1080px 幅に合わせて 文字数 を絞り込み。 旧 20字 / 14字 → 新 11字 / 8字 (fontSize 84 / 122 の場合)。

  • fontSize 84 (normal/normal_emphasis): 20字 → 11字
  • fontSize 84 third_party (通常モード): 18字 → 9字 (｢ ｣ 占有 +2)
  • fontSize 108 (theme): 16字 → 9字
  • fontSize 122 (emphasis 系): 14字 → 8字
✂️ 改行ルール: 単語の途中で切らない

テロップ分割位置は 助詞 (は/の/に/を/が/で/も/て/と) の後 / 動詞活用語尾の後 / 名詞境界 で切る。 「ボ│レーが」 「ストレ│ートを」 のように単語の途中で切る分割は禁止。

🎤 対談動画モード (dialogVideo) + interviewee テンプレ追加

step01-context で「対談 / インタビュー動画ですか？」 を確認。 対談動画モード時は transcript を内容分析して インタビュアー (発信者) / インタビュイー (ゲスト) を自動分類し、 ゲストには新テンプレ interviewee (teal 色・normal と同型 SVG) を適用。

  • 新テンプレ interviewee: NORMAL_VARIANTS の cyan variant (teal 系) で normal (紺) と視覚区別。 対談 / インタビュー動画でゲストの発話に使う
  • 新テンプレ interviewee_emphasis: normal_emphasis のインタビュイー版 (teal ベース + 赤強調)。 ゲストの 1 語強調でもベース色が teal で維持される
  • インタビュアー (発信者・質問する側): normal / normal_emphasis (紺) をそのまま使用。 チャンネルの顔は既存色で統一
  • 判定アルゴリズム: 質問パターン (?, ですか, 教えてください) / 紹介パターン (お越しいただきました) / 短い相槌 (なるほど) → インタビュアー。 該当しない長めの発話 → インタビュイー
  • third_party の ｢｣ 自動付与は OFF にしない: 対談動画でも視聴者の声を引用する場面で従来通り使用
🔊 SE 音量を 0.1 → 0.04 に下げる (-20dB → -28dB)

受講生から「SE が少し大きい」 と指摘あり。 旧仕様は BGM の -20dB ルールと同じ位置に SE があったため大きく聞こえていた。 新仕様で -28dB に統一 (BGM 0.03 の +2.5dB 上で聞こえる・メインから -28dB で邪魔しない)。 CLAUDE.md「音量基準」 セクションも業界経験則ベースで書き換え。
