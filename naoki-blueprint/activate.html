UPアップデート（v2.6+ Private リポ対応）

基本は自動。 v2.6+ では初回 1 回だけ gh auth login が必要です。

各 step 実行時に内部で 24時間に1回だけ 最新版チェックが走り、新しいバージョンがあれば自動でダウンロード・適用されます。作業中の素材（public/）・テロップデータ（src/*.tsx）・transcript は保護されるので、いつ自動更新が走っても作業は壊れません。

更新があると Claude Code のログに以下のようなメッセージが一瞬表示されます:

📦 naoki-blueprint v2.6.0 → v2.6.1 に自動更新中...
✓ 更新完了
🔒 v2.6+ で本リポは Private 化されました。 初回 1 回だけ以下を実行:
gh auth login # Mac/Win 共通・ブラウザ認証 1 分
Naoki から届いた招待メール (「Invitation to coach-naoki/naoki-blueprint」) を Accept してから gh auth login を実行してください。

※ どうしても今すぐ最新版にしたい場合: Claude Code を Ctrl+C を 2回 押して終了し、通常ターミナルで以下を実行:

cd ~/Desktop/Cursor/naoki-blueprint && bash アップデート.sh

通常は自動更新に任せてOKです。
