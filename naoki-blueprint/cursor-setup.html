Naoki's Blueprint / Setup

Cursor セットアップガイド

Cursor をまだインストールしていない方向け。 セットアップ完了まで 15-30 分。

🍎 Mac 版 🪟 Windows 版

01Cursor をダウンロード

⏱ 所要時間: 3〜5分🎯 ゴール: .dmg ファイルがダウンロードフォルダに保存された状態

Cursor は 「AI 付きのコードエディタ」 です。 これがあなたの作業場になります。 動画テンプレートを開いたり、 AI (Claude) に指示を出したり、 すべてこの中で完結します。

手順

  1. 公式サイトにアクセス: https://cursor.com/
  2. 中央の 「Download for macOS」 ボタンをクリック
  3. .dmg ファイルがダウンロードされる (約 200MB)

02Cursor をインストール

⏱ 所要時間: 2〜3分🎯 ゴール: アプリケーションフォルダに Cursor が入った状態

手順

  1. ダウンロードした .dmg ファイルをダブルクリック
  2. ウィンドウが開いたら、 Cursor アイコンを 「Applications」 フォルダにドラッグ
  3. Launchpad または Finder → アプリケーション から Cursor を起動
⚠ エラー: 「"Cursor" は開発元を検証できないため開けません」
通常は表示されません (現行 Cursor は Apple 署名済み)。 もし出たら:
システム設定 → プライバシーとセキュリティ → 下にスクロール → 「"Cursor" は開発元を検証できないためブロックされました」 の右の 「このまま開く」 をクリック。

03初回セットアップ

⏱ 所要時間: 3〜5分🎯 ゴール: Cursor のメイン画面が開いた状態

手順

  1. Cursor を起動すると、 アカウントログイン画面が出る
  2. 「Sign in with GitHub」 をクリック
    → GitHub アカウント未作成の場合は https://github.com/join で先に作成
  3. ブラウザで GitHub にログイン → 「Authorize Cursor」 をクリック → Cursor に戻る
  4. もし 「What language do you primarily use?」 と聞かれたら 「TypeScript」 を選択
    → 出ない場合 (現行版ではスキップされることが多い) はそのまま次へ
  5. メイン画面が開く。 以下の 3 エリアがあることを確認:
    • 左サイドバー: ファイル一覧 / 検索 / Agents / Chat 等のアイコン列
    • 中央: コード編集エリア (まだファイルは開いていない)
    • 下部: ターミナル (隠れている場合は Command+J で開く)

04環境セットアップ (初回のみ)

⏱ 所要時間: 5〜15分🎯 ゴール: 動画制作に必要なツール (Git / Node.js / FFmpeg / GitHub CLI / Python / Claude Code / Whisper) が全部入った状態

すでに入っているツールはスキップ OK。 1 行のコマンドで全部まとめてインストールします。

① 全ツールを 1 行でインストール

Cursor 下部のターミナルで以下のコマンドをコピペして Enter:

[ -x /opt/homebrew/bin/brew ] || /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && eval "$(/opt/homebrew/bin/brew shellenv)" && brew install git node ffmpeg gh python@3.12 && brew install --cask claude-code@latest && /opt/homebrew/bin/pip3.12 install mlx-whisper --break-system-packages

② GitHub にログイン

ターミナルで以下を実行:

gh auth login

プロンプトに従って:

  • What account do you want to log into? → GitHub.com
  • What is your preferred protocol? → HTTPS
  • Authenticate Git with your GitHub credentials? → Y
  • How would you like to authenticate? → Login with a web browser
  • 表示された 8 桁コードをブラウザに入力 → 認証完了 (1 分)

③ インストール確認

ターミナルで以下を実行:

git --version && node --version && gh --version && claude --version && /opt/homebrew/bin/python3.12 --version && /opt/homebrew/bin/python3.12 -c "import mlx_whisper; print('whisper OK')"

5 つのバージョン番号 + whisper OK が表示されれば成功。

05Claude Code を起動する

⏱ 所要時間: 3〜5分🎯 ゴール: ターミナルで claude --dangerously-skip-permissions を打つと、 オレンジのカニキャラクターが表示された状態

Claude Code は AI アシスタント 「Claude」 をターミナルから直接使えるようにするツールです。 これを使って 「テロップを入れて」 「SE を追加して」 と日本語で指示します。

手順

  1. Cursor 下部のターミナルで以下を実行:
claude --dangerously-skip-permissions
  1. 初回のみ認証画面が出るので、 ブラウザで Anthropic にログインしてください。
  2. オレンジのカニキャラクターが表示されれば成功 🦀
⚠ エラー: 「command not found: claude」 や 「claude: command not found」
PATH が反映されていません。 Cursor を完全に終了 (Cmd+Q) → 再起動して、 もう一度ターミナルで上のコマンドを実行してください。

✓セットアップ完了!

これで Cursor + 環境ツール + Claude Code がすべて動く状態になりました。

01Cursor をダウンロード

手順

  1. 公式サイトにアクセス: https://cursor.com/
  2. 中央の 「Download for Windows」 ボタンをクリック
  3. 通常は 「User Installer (推奨)」 を選択
    • User Installer: 管理者権限不要、 自分専用にインストール (おすすめ)
    • System Installer: 管理者権限が必要、 PC 全体にインストール
  4. .exe ファイルがダウンロードされる (約 200MB)

02Cursor をインストール

⏱ 所要時間: 2〜3分🎯 ゴール: スタートメニューに 「Cursor」 が追加された状態

手順

  1. ダウンロードした .exe ファイルをダブルクリック
  2. インストール画面が出たら、 全てデフォルト設定のまま 「Next」 → 「Install」 を進める
  3. 「Run Cursor」 にチェックが入った状態で 「Finish」 をクリック → Cursor が起動
⚠ エラー: 「Windows によって PC が保護されました」 (SmartScreen)
「詳細情報」 をクリック → 「実行」 ボタンを押す。 これは Microsoft の新しいアプリへの警告で、 Cursor 自体は安全です。
